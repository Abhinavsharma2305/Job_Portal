# Job Hunt — Team Job Portal Project

A full-stack MERN Job Portal built as a college team project.

**Team**: Abhinav Sharma · Abhay · Akshat  
**Repository**: https://github.com/Abhinavsharma2305/Job_Portal  
**Reference Project**: https://github.com/ankitpathak62/JOB-PORTAL (by Ankit Pathak — used as starting reference)

## Project Location

All source code is inside the [`JOB-PORTAL/`](./JOB-PORTAL/) folder.

- **Backend**: `JOB-PORTAL/Backend/` — Node.js + Express + MongoDB
- **Frontend**: `JOB-PORTAL/Frontend/` — React 18 + Vite + Tailwind CSS
- **Setup Guide**: See [`JOB-PORTAL/README.md`](./JOB-PORTAL/README.md)
- **Team Tasks**: See [`JOB-PORTAL/TEAM_TASKS.md`](./JOB-PORTAL/TEAM_TASKS.md)

## Quick Start

```bash
# Backend
cd JOB-PORTAL/Backend
npm install
# Copy example.env to .env and fill in your credentials
npm run dev          # runs on http://localhost:5011

# Frontend (new terminal)
cd JOB-PORTAL/Frontend
npm install
npm run dev          # runs on http://localhost:5173
```

## Tech Stack

| Layer | Technology |
|-------|-----------|
| Frontend | React 18 + Vite + Redux Toolkit + Tailwind CSS |
| Backend | Node.js + Express 4 |
| Database | MongoDB + Mongoose |
| Auth | JWT + bcryptjs + Email OTP (Nodemailer) |
| Uploads | Cloudinary |
| AI | OpenAI-compatible recommendations |
